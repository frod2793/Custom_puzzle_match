# 게임 기획서: Gravity Spin Match (가제)문서 버전: 1.1작성일: 2025년 12월 5일장르: 물리 기반 퍼즐 / 매치-3 (Match-3)타겟 플랫폼: 모바일 (Android / iOS)개발 엔진: Unity 2D1. 게임 개요 (Game Overview)1.1. 컨셉 (High Concept)"세상을 돌려라, 중력이 바뀐다!" > 고정된 방향으로만 떨어지는 기존 퍼즐과 달리, 플레이어가 보드를 회전시켜 중력의 방향을 바꾸며 전략적으로 블록을 매칭하는 퍼즐 게임.1.2. 핵심 재미 요소 (Core Fun)공간 지각의 재미: 보드를 회전시켰을 때 블록이 어떻게 쏟아질지 예측하는 즐거움.연쇄의 쾌감: 중력 변화로 인해 예상치 못한 곳에서 터지는 콤보(Cascade) 효과.수집과 꾸미기: 다양한 테마 스킨을 수집하여 나만의 게임 화면을 연출하는 만족감.나만의 퍼즐 만들기: 내 사진첩의 이미지를 업로드하고 직접 자(Crop) 퍼즐 블록으로 사용하는 창작의 재미. (신규 추가)2. 핵심 게임 메카닉 (Core Mechanics)2.1. 기본 규칙보드 크기: 7x7 또는 8x8 그리드.매칭 규칙: 동일한 색상/모양의 블록 3개 이상이 상하좌우로 인접하면 파괴됨.클리어 조건: 제한된 턴(회전 수) 내에 목표 점수 도달 또는 특정 블록 제거.2.2. 중력 회전 시스템 (Gravity Spin)조작: 화면 하단 버튼 터치 또는 화면 스와이프로 보드를 90도(시계/반시계) 회전.물리 작용:회전 즉시 새로운 '아래' 방향이 결정됨.모든 블록은 새로운 중력 방향으로 낙하하여 빈 공간을 채움.낙하 후 매칭 판정 진행.전략 요소: 구석에 박혀 움직일 수 없는 블록을 회전시켜 중앙으로 꺼내거나, 멀리 떨어진 블록을 중력으로 붙여 매칭 유도.2.3. 특수 블록 (Gimmicks)고정 블록 (Anchor): 중력의 영향을 받지 않고 제자리에 고정된 장애물.무거운 블록 (Heavy): 다른 블록보다 빨리 떨어지며, 떨어지는 경로에 있는 약한 장애물을 부숨.3. 커스터마이징 시스템 (Customization System)3.1. 시스템 개요유저는 게임 플레이 보상(골드)이나 업적 달성을 통해 \*\*'테마(Theme)'\*\*를 해금하고 장착할 수 있음. 테마는 단순히 이미지만 바꾸는 것이 아니라 시각/청각적 피드백을 모두 포함함.3.2. 커스터마이징 범위 (Theme Components)하나의 테마는 ScriptableObject 데이터로 관리하며 다음 요소를 포함함.구분설명구현 예시블록 스킨5~6종의 기본 블록 디자인 변경보석 $\\rightarrow$ 행성 $\\rightarrow$ 스포츠공배경 (BG)게임 플레이 배경 이미지 변경단색 $\\rightarrow$ 우주 은하수 $\\rightarrow$ 경기장 잔디UI 인디케이터현재 중력 방향을 알려주는 화살표 디자인화살표 $\\rightarrow$ 로켓 엔진 $\\rightarrow$ 심판 손가락VFX (이펙트)회전 시 잔상, 블록 파괴 이펙트빛줄기 $\\rightarrow$ 별가루 $\\rightarrow$ 땀방울/스피드선SFX (사운드)블록 이동음, 회전 효과음틱톡 $\\rightarrow$ 기계음(우웅) $\\rightarrow$ 호루라기(삑)(신규) 유저 업로드 스킨유저가 직접 업로드하고 자른 이미지내 고양이 사진, 직접 그린 그림 등3.3. 테마 기획안 (예시)A. 테마: 갤럭시 트래블 (Galaxy Travel)컨셉: 광활한 우주와 행성.블록: 태양(빨강), 지구(파랑), 숲행성(초록), 금성(노랑), 블랙홀(특수 블록).특수 효과: 보드 회전 시 별똥별이 흐르는 잔상 효과. 중력 방향은 '로켓'이 가리킴.B. 테마: 스포츠 리그 (Sports League)컨셉: 역동적인 스포츠 경기장.블록: 농구공, 축구공, 야구공, 테니스공, 당구공.특수 효과: 블록 파괴 시 관중 함성 소리(약하게). 보드 회전 시 심판의 휘슬 소리.C. 테마: 레트로 픽셀 (Retro Pixel)컨셉: 8-bit 고전 게임 감성.블록: 픽셀 아트 형태의 슬라임, 포션, 검, 방패.특수 효과: 칩튠(Chiptune) 스타일의 전자음 효과음.4. UI/UX 디자인 가이드4.1. 메인 화면 (Lobby)플레이 버튼: 가장 최근 스테이지 이어하기.커스텀(상점) 버튼: 현재 장착 중인 스킨의 대표 아이콘 표시.재화 표시: 골드 / 하트.4.2. 커스텀 편집 화면 (Closet/Shop)커스텀 모드 (Mix \& Match): 단순히 정해진 테마 세트를 구매하는 것뿐만 아니라, 유저가 각 요소를 개별적으로 선택하여 조합 가능.편집 탭(Tab) 구성:블록(Block): 모양(보석, 행성 등) 선택 및 색상 팔레트 변경 기능. \[+ 이미지 업로드] 버튼 추가.배경(BackGround): 보드판 프레임 및 배경 이미지 교체.이펙트(Effect): 회전 잔상, 블록 파괴 파티클, 사운드 팩 선택.미리보기 창: 유저가 조합한 옵션이 실시간으로 반영되는 4x4 미니 보드 제공 (회전/드래그 테스트 가능).나만의 프리셋: 유저가 직접 조합한 커스텀 설정을 'My Style' 슬롯에 저장하고 불러오는 기능.4.2.1. 이미지 업로드 및 편집 프로세스 (신규 추가)유저가 '블록' 편집 탭에서 \[+ 이미지 업로드] 버튼을 눌렀을 때의 UX 흐름입니다.사진 앱 접근 권한 요청: OS 기본 팝업으로 갤러리 접근 권한을 요청합니다.이미지 선택: 유저가 기기의 사진 앱에서 원하는 이미지를 선택합니다.이미지 자르기(Crop) 화면 진입:불러온 이미지가 화면 중앙에 표시됩니다.이미지 위에 정사각형(1:1 비율) 크롭 가이드 박스가 오버레이 됩니다.유저는 이미지를 확대/축소/이동하여 가이드 박스 안에 원하는 영역을 맞춥니다.하단에 \[취소] / \[완료] 버튼이 있습니다.블록 지정 및 저장:\[완료] 버튼을 누르면 잘린 이미지가 '나만의 블록 리스트'에 추가됩니다.유저는 이 이미지를 특정 색상 블록(예: 빨강 블록)을 대체하는 스킨으로 지정할 수 있습니다.지정 즉시 미리보기 창에 반영됩니다.4.3. 인게임 HUD중력 인디케이터: 화면 테두리 혹은 보드 배경 뒤편에 \*\*현재 중력 방향(아래)\*\*을 명확히 표시. (필수 UX 요소)회전 버튼: 화면 하단 좌/우에 90도 회전 아이콘 배치.5. 기술 구현 명세 (Technical Specs - Unity)5.1. 데이터 구조ThemeData (ScriptableObject): 테마 이름, 스프라이트 배열, 오디오 클립, 파티클 프리팹 등을 담는 컨테이너.ThemeManager (Singleton): PlayerPrefs에서 유저가 선택한 ThemeID를 로드하고, 게임 시작 시 리소스를 교체하는 역할.UserCustomBlockData: 유저가 업로드한 이미지 경로와 해당 이미지가 대체할 블록 타입을 매핑하여 로컬에 저장하는 데이터 구조 필요.5.2. 물리 및 이동 로직Grid System: 논리적 위치(Grid$$x,y$$) 관리.Visual Movement: DoTween 등을 사용하여 논리적 위치로 부드럽게 이동.Rotation: 보드 전체를 회전시키는 것이 아니라, \*\*'카메라를 회전'\*\*시키거나 \*\*'블록의 목표 지점을 재계산'\*\*하는 방식 중 택 1.권장: 보드 프레임(Container) 자체를 회전시키되, 내부 블록 스프라이트는 역회전시켜 정방향을 유지하거나, 중력 방향만 바꾸고 블록이 떨어지는 애니메이션 구현.5.3. 이미지 업로드 및 처리 (신규 추가)Native Gallery Plugin: Android/iOS 사진 앱 접근을 위해 유니티 에셋 스토어의 네이티브 갤러리 플러그인 활용 권장.Texture Processing: 불러온 이미지를 Texture2D로 변환하고, UI 상에서 크롭한 영역 좌표를 계산하여 새로운 Texture2D 또는 Sprite를 생성.Local Storage: 생성된 커스텀 블록 이미지는 Application.persistentDataPath 등 로컬 저장소에 파일 형태로 저장하고, 게임 실행 시 로드하여 사용.6. 개발 마일스톤 (Milestones)프로토타입 (1주차):기본 매치-3 로직 구현.버튼 클릭 시 보드 90도 회전 및 블록 재배치 구현.알파 버전 (2~3주차):스테이지 시스템 및 점수 로직.기본 테마(보석) 아트 적용.특수 블록 1종 구현.베타 버전 (4주차):커스터마이징 시스템 연동 (ScriptableObject).추가 테마 2종(우주, 스포츠) 제작 및 적용.UI/UX 폴리싱.기능 추가 및 최적화 (5주차~):유저 이미지 업로드 및 크롭 기능 구현.
